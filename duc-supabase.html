Hướng dẫn kết nối / vì sao trang này khác các module trước

SUPABASE_URL / SUPABASE_ANON_KEY đã điền sẵn ở đầu thẻ <script> (cùng project với các trang pilot khác) — mở trang qua https:// (GitHub Pages hoặc mở file local đều được, PostgREST không chặn CORS).

  1. Chạy supabase/schema_duc.sql trong Supabase SQL Editor (nếu chưa chạy).
  2. Chạy supabase/import-duc.mjs để nạp dữ liệu — script này đọc trực tiếp qua Google Sheets API bằng service account, KHÔNG qua publish-to-web (xem comment đầu file để biết cách tạo service account).
  3. Bấm "🔄 Làm mới" ở góc phải để tải lại.

Trang này chỉ hiện 4 bảng lõi (Ca đang chạy / Sự cố / Báo cáo ca / Shot khuôn) trong tổng số 16 bảng đã tạo ở schema_duc.sql (còn thiếu IPQC_Checkpoint, IPQC_TieuChuan, SP_Khong_Phu_Hop, Van_De_Khuon, TangCa_Log, Shot_May, Lich_Su_SanXuat, Diecast log theo phút, In tem — bỏ qua ở bản pilot đầu để rút gọn scope, có thể bổ sung tab sau khi 4 bảng lõi đối chiếu ổn định).
